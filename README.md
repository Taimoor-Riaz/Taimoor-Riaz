## About me

I build Unity games from concept to launch: mobile, PC, and real-time multiplayer. I've been developing games professionally since 2019, and I currently work as a **Senior Game Developer at Inventix Games** and **CTO at Cipher Coders**, where I lead a team of Unity developers.

- 🎮 Gameplay programming, game architecture, and performance optimization
- 🌐 Real-time multiplayer with Photon Fusion / PUN and Socket.IO
- ⚙️ Game backends and APIs with NestJS, Firebase, PlayFab, MongoDB, and SQL
- 📱 Mobile monetization with AdMob, Unity Ads, and in-app purchases
- 💼 **Open to freelance projects.** [Get in touch](mailto:mughaltaimoor298@gmail.com)
